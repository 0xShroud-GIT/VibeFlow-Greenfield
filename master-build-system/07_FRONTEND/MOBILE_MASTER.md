# Mobile Master

Technology: Expo/React Native. Mobile is first-class, but it is not a native reimplementation of every IDE surface.

Navigation target:
- Home
- Create
- Projects
- Project overview
- Agent/Task
- Action Center / Approvals
- Notifications
- Connections / Providers
- Recovery / Evidence summaries
- Account / Organization / Billing
- Workspace launch/embedded workspace

Secure storage holds session material appropriate for the client, never raw cross-provider project secrets. Push notifications are projections of durable Notification/Approval/Execution state.
