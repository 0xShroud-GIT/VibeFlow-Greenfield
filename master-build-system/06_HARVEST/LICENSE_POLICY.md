# Dependency / License Policy

Default green: MIT, BSD, Apache-2.0, ISC, PostgreSQL and similarly permissive dependencies.

Review-required: LGPL/file-level copyleft, MPL, open-core SDKs, SSPL/BSL/source-available terms, network copyleft, non-commercial or field-of-use restrictions.

Never copy third-party code merely because it is visible on GitHub. Use dependency/vendor/fork according to license and maintenance strategy. AGPL tools may be used externally for analysis, but production incorporation requires explicit legal/architecture review.

Every dependency registry entry records approved version/version line, license classification, use, ownership boundary, upgrade policy and replacement strategy. Exact installable package pins are recorded in the repository lockfile starting with Mission 004 (Repository Foundation), not in this registry.
