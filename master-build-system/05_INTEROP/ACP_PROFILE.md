# ACP Profile

Target the current stable ACP schema line, pinning the exact schema/SDK artifacts in Mission 009. Do not adopt unstable v2 features in core behavior without a compatibility gate.

VibeFlow uses ACP for coding-agent session/message/tool-call interoperability. VibeFlow does **not** delegate durable Task/Execution authority, cross-device replay, ConnectionGrant policy, or verification authority to ACP.
