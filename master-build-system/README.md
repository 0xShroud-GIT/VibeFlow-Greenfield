**Version:** 1.0

1. **Global truth** — complete architecture/product/frontend/backend/AI/security/verification/harvest contracts.
2. **Local mission context** — small, bounded packets for Arena/Codex/Claude/OpenHands or another coding agent.

The core rule is: **comprehensive source of truth; minimal execution context.**

Start with `ARENA_START_HERE.md`, then `00_MASTER/MASTER_OF_MASTERS.md`.
