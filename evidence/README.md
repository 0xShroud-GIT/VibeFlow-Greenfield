# evidence

PR/release/test/verification evidence. Local ephemeral output belongs under `evidence/local` and is ignored.

`evidence/missions/` is retained historical proof of what a mission demonstrated at review/acceptance time. Evidence is not the current mission packet and must not be used to infer current build order, status, or implementation scope. Use `.ai/ACTIVE_MISSION.md` and `master-build-system/10_IMPLEMENTATION/MISSION_DAG.yaml` for current work.

Do not delete retained mission evidence merely because a mission is complete.
